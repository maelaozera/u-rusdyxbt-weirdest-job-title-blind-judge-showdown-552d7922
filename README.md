## How to run

Requires Node 22 or later (the program is plain TypeScript, run as-is):

```sh
node main.ts
```

It writes exactly the title above — and nothing else, no trailing newline —
to `/output/entry.txt`. The program is deterministic: no input, no network,
no randomness, so every run produces the same bytes.
